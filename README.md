# Continuous-Variable Quantum Error Correction Using Topological GKP Codes

**M.Sc. Thesis | Physics, IIT Madras**

## Overview

This thesis investigates continuous-variable quantum error correction using Gottesman–Kitaev–Preskill (GKP) encoding and multi-genus topological architectures. The work focuses on lattice-based decoding, logical fidelity, error-correction thresholds, and encoding efficiency.

## Research Highlights

- Studied multi-genus topological GKP architectures for multi-qubit bosonic quantum error correction.
- Implemented lattice-based decoding algorithms and large-scale Monte Carlo simulations in Python.
- Evaluated logical fidelity and error-correction thresholds across code distances and noise strengths.
- Compared multi-genus toric-code constructions with rotated surface-code-based GKP architectures.
